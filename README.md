# RISC-ISA-Generator

Инструмент для автоматической генерации и упаковки битовых полей инструкций кастомной RISC-архитектуры на основе JSON-спецификации. Само задание и примеры можно посмотреть в файле `task/task.pdf`

## Требования

- C++ компилятор с поддержкой стандарта C++17
- CMake (версии 3.14 или новее)

## Сборка проекта


```bash
cmake -S . -B build && cmake --build build  
```

Недостающие зависимости (`nlohmann_json` и `GoogleTest`) будут загружены автоматически

## Запуск

Для запуска программы укажите путь к файлу с  конфигурацией:

```bash
./build/risk_isa_generator.x assets/input.json
```

Сгенерированная структура команд будет сохранена в файл `assets/output.json`. 
Пример содержимого `input.json` можно посмотреть в директории `assets/`.

## Тестирование

Тесты построены на базе GoogleTest. Бинарник с тестами собирается автоматически в виде отдельной цели.

Запуск через CTest (рекомендуется):
```bash
cd build
ctest -V --output-on-failure
```

Или вызов бинарника напрямую для получения подробного вывода:
```bash
./risk_isa_tests
```
